# 個別の支援・指導計画 作成支援ツール v46

中学校・特別支援学級などで利用する、**個別の教育支援計画・個別の指導計画をブラウザ上で作成・整理する単体HTMLアプリ**です。

> **まず使ってみる方へ:** `index.html` を Chrome または Microsoft Edge で開いてください。インストールやサーバー接続は基本的に必要ありません。

## まず10分で使う

1. `index.html` を開く
2. ホームの **「10分で始める」** を選ぶ
3. 氏名・学年・学級などの基本情報を入力
4. 実態 → 願い → 目標 → 支援 → 評価を入力
5. 保存状態を確認
6. 重要な計画は **データ管理 → JSONバックアップ** で保存

詳しい操作は [`MANUAL.md`](MANUAL.md) をご覧ください。

## Excelを使う場合

既存の `.xlsx` ファイルがある場合は、アプリの **Excel取り込み** を利用できます。

- 元のExcelファイルは変更しません。
- 取り込み内容を確認・修正してから計画として登録します。
- この版の対象は **`.xlsx`** です。古い `.xls` は対象外です。
- Excelの日付やカスタム日付形式にも対応しています。

## データの保存について

このアプリは、入力データを基本的に**使用中のブラウザのローカル保存領域**に保存します。

そのため、PCの交換、ブラウザの初期化、保存領域の消去などに備えて、重要なデータは定期的にJSONバックアップしてください。

個人情報を含むJSONは、学校の個人情報管理ルールに従って安全に保管してください。

## 年度更新・保管

- **次年度へ**：前年度の計画を土台に新年度の計画を作成します。
- 前年度の評価・同意・確認・記入情報は、新年度に再確認するため自動継承しません。
- 学年は自動進級させず、実際の在籍情報を確認して入力します。
- 卒業・転出などは、原則として完全削除ではなく **保管** を利用します。
- 保管した計画は、データ管理から確認・復元できます。

## セキュリティ上の注意

この単体版には、ログイン、サーバー側承認フロー、サーバー監査ログなどはありません。

個人情報を扱う際は、学校・自治体等の情報管理規程に従ってください。

詳しくは [`SECURITY.md`](SECURITY.md) をご覧ください。

## GitHubへの登録

初めてGitHubへ登録する場合は [`GITHUB_UPLOAD_GUIDE.md`](GITHUB_UPLOAD_GUIDE.md) を先に読んでください。


このフォルダーの中身をGitHubリポジトリのルートへ配置してください。

GitHub Pagesを利用する場合は、`index.html` がルートにあるため、そのままWeb公開できます。

### 注意

このアプリはブラウザ内にデータを保存するため、GitHubに**個人情報を含むJSONバックアップや実際の児童生徒データをアップロードしないでください**。
